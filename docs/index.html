3 · Resultados

Todos os métodos de avaliação

Os critérios nem sempre concordam: o VPL mede riqueza criada, o RAU anualiza para comparar vidas diferentes, a TIR e o payback favorecem projetos menores e mais rápidos, o IBC mede valor por unidade investida.

4 · Análise marginal

Fluxo de caixa marginal entre todos os pares

Para cada par, o projeto de menor investimento é o defensor e o de maior é o desafiante. Com vidas diferentes os fluxos são empilhados até o mínimo múltiplo comum (ou estendidos, sem repetição). O desafiante vence quando o VPL marginal à TMA é positivo.

Matriz de decisão

Desafiante (linha) × defensor (coluna): azul = desafiante vence; vermelho = defensor vence

Clique numa célula para abrir o par. * = fluxo marginal com mais de uma TIR; — = investimentos iguais (compare os VPL diretamente).

5 · Carteiras

Combinações de projetos independentes

O VPL de uma carteira é a soma dos VPL dos projetos. A soma dos RAU supõe repetição dos projetos ao fim das vidas. Ajuste o número de projetos e o orçamento nas premissas.
